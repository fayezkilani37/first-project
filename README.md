# 🏋️ صالة القوة | Power Gym Landing Page

صفحة هبوط (Landing Page) لصالة رياضية، مبنية بالكامل بـ **HTML** و **CSS** فقط، بدون أي مكتبات أو frameworks خارجية.

## 🔗 معاينة حية
شاهد الموقع مباشرة من هنا:
**[fayezkilani37.github.io/first-project](https://fayezkilani37.github.io/first-project/)**

## ✨ المميزات
- تصميم متجاوب (Responsive) يشتغل على الموبايل والتابلت وسطح المكتب
- حركات وانتقالات سلسة (Transitions & Animations) على العناصر الأساسية
- قائمة تنقل (Navigation) وقسم حصص تدريبية وقسم "عن الصالة"

## 🛠️ التقنيات المستخدمة
- HTML5
- CSS3 (Flexbox، Media Queries، Keyframe Animations)

## 📂 الملفات
| الملف | الوصف |
|---|---|
| `index.html` | هيكل الصفحة |
| `style.css` | كل التنسيقات والحركات |

## 📌 ملاحظة
هاد المشروع جزء من رحلتي بتعلم تطوير الويب، وبيركز بشكل أساسي على أساسيات CSS (التخطيط، الانتقالات، الحركات، والتصميم المتجاوب).
